## 行为与工程范围

结束旅程仍由原 `KittRuntime.end()` → `TripStore.finish()` 自动保存轻量纪要，再显示标题、时长、跳过次数、已讲主题（无主题时安静文案）和“回到出发页”。仅显示已有明确目的地，空值/未询问/未提供/等待回答不显示；不修改 JSON 中原目的地。移除五项评分、默认分数、意见框、保存评分按钮及专用提示，清理无其他调用的评分写入接口。

原自动保存时序、原子写入、恢复和既有最多20份纪要保留策略不变；没有迁移、扫描重写或清空旧文件。历史 `ratings`/`feedback` 额外字段仍由原读取器忽略。读取、显示、返回均不修改记录；新纪要不含评分字段。没有新增手动保存、分类偏好、在线请求、定位/语音改动或知识包。

Compose/Robolectric 检查评分/评语/数字选择与文本输入不存在、明确/技术目的地区别、空主题文案、竖屏/小横屏/平板返回可见，以及实际 MainActivity 结束按钮自动保存后直接返回。持久化样本读取遗留评分并逐字节对照，保存另一趟后旧文件不变，同时保留损坏恢复安全断言。合成环境不能证明真机布局或私有历史数据实际状态。

## 用户另行批准原位升级后的最短真机步骤

1. 先核候选 SHA256、`com.kitt.reader.runtimecheck`、0.4.2/code16 和唯一原证书，再读取手机实际版本/签名。只有本轮得到新的升级授权且安全核验通过，才允许原签名 `adb install -r`；不卸载、不清数据、不降级、不用标准 `com.kitt.reader` 替换。已是16或更高时停止重复安装。
2. 升级前后核对可见账号和已保存设置。普通“开始沿途”不问目的地；结束一趟未提供目的地、未讲主题的旅程，确认安静文案、时长/跳过数，无技术目的地、评分、评语或保存按钮。“回到出发页”一次返回，旅程/前台服务结束。
3. 安全停车或乘客状态，有新鲜可信新都真实位置时，让本地自动故事完成后结束，确认主题纪要；若主动提供目的地，结束页可显示。竖屏、小横屏/平板（设备具备时）检查返回按钮和布局。联网自动Director/Research调用增量仍0，无真人新证据时保留PENDING。
4. 用只读、有界且脱敏的方法核纪要在返回前已保存、返回后仍存在；旧含评分记录可读取且未被本次 UI 显示/返回改写。不要为核验导出原始账号、私人聊天、录音或 GPS。当前没有新增历史浏览页面，不能用不存在的 UI 假称旧数据已验证。
5. 记录本版真实 PASS/PENDING 后 STOP，不合并、不进入V0.5.0。#24 的断网新鲜定位→完整地方讲述、重播/有限问答、同旅程云失败后本地恢复等仍需独立外场验收。
