## 1. 产品身份、受众与成功定义（P0）

- **KITT 首先是“位置感知的 AI 旅行助手 / 旅行伙伴”，不是历史助手、专业地理研究工具、百科阅读器或导航替代。** “一部跟着汽车移动、能够互动的地理人文百科”用于形容其知识覆盖，不限制旅行助手的实际交互能力。
- 内容气质参考**《中国国家地理》的知识广度及《航拍中国》的地理人文视角和通俗叙述**，但绝不未经授权复制文章、影像、旁白或独创表达。
- **目标受众是路过此地的普通游客**：假定没有专业背景，也未事先读过当地历史、地理和人物。知识上游可以深，首次开口必须浅显、有上下文、自然、有趣，不讲成课堂、论文、年表或术语汇报。
- 评价一段内容首先问：**“此时此地的普通乘客为什么值得听？听完能理解并记住什么？”** 依照当前位置/旅行需求相关性、真实可靠性、趣味性/实际价值、新颖度与避免重复来选择，而不是规定历史百分比。
- 有可靠且值得听的历史、人文、自然、工程或生活故事就讲；没有适合且可证实的内容就安静。宁缺毋滥，不为覆盖率填词。
- “懂山河、懂地理、懂人文、懂生活、懂历史、懂旅行”是并列能力。历史是有深度的特长，**不是强制最优先或唯一主内容**。将来可以考虑简洁的讲述偏好选项，但其界面、档位、默认值均非此版已实施契约，不能写死历史比例。

## 2. 内容覆盖范围与空间组织

### 六类并列内容

1. **山河、地理与自然生态**：山脉、江河、峡谷、地貌成因、地质、气候规律、植被、动物、自然现象与保护。
2. **道路、交通与重大工程**：古道、公路、桥梁、隧道、铁路、航运、水利、能源工程；地形约束与工程智慧。
3. **人文、文化和社会**：地域文化、民族语言、宗教与信仰的客观介绍、建筑、艺术、非遗、风俗、聚落与社区。
4. **物产、产业与生活**：饮食、农业、手工艺、贸易、市场、地方特产、工业、城市与乡村日常。
5. **历史与人物**：人物经历、地方史、古国、历史事件、遗址、军事与交通史、地名演变；解释其与今天风物的关系。
6. **旅行现场与常识**：旅途上值得注意的现象、观景背景、地域差异、常见旅行问题。**当前天气、路况、营业、票价、临时活动只从可靠实时渠道获取；没有网络或可信数据就说明不能确认**，不得从离线长期包冒充现况。

类型是**多标签**，没有固定篇幅配比，也不能规定按类别轮流播放。一个高价值对象可跨越地质、工程、历史和当地生活。

### 空间层次

- **区/县**负责行政背景、地理及地域性介绍；
- **镇/乡/街道**作为沿途内容组织的常用单元（前提是地名及归属有可靠依据）；
- **具体对象**（一座桥、一处遗址、一个村落、一种物产、一段山路、一个人物）承载可讲内容；
- **跨区关系**（山系、河流、古道、重大工程与跨地人物事件）可链接多个区域，防止被行政区边界切碎。
- 必须区分“**此事与该区有关**”和“**此物就在车辆附近/肉眼可见**”。后者需要新鲜、精度足够的位置和可信地理位置/范围，不得用历史关联推断所见。

## 3. 对普通游客的讲述标准（P0，与事实准确性同级）

**讲述顺序是理解顺序，不是强制作文模板。**

- **先给背景**：现在在哪里/这是什么东西/为什么与沿途有关。遇到生僻人名、时期、地质或工程词，先以普通话解释。
- **突出一个值得听的现象或故事**：一次主动讲述通常只深入一个主要角度；不要一次读完对象的全部档案。
- **循序解释“为什么”**：用易懂例子帮助理解，再给必要的准确专业名称；数字和年代只取理解必需的部分。
- **愿意听才延伸**：用户说“再讲一点”“为什么”再补更多事实、深度因果、相关人物和争议；要说明哪些已说过，不重复基础介绍。
- **不低幼、不卖弄、不刻意煽情**；自然口语、不居高临下，没有证据的因果推断不包装成有趣定论。
- 编辑每个主题时建议具备：`traveler_intro`（零背景认识）、`why_interesting`（沿途价值）、`plain_language_notes`（术语白话解释）、`followup_angles`（愿意深入的方向）。这属于**生产端内容字段建议**，不强迫 #20 当前 Android Schema 立即增加，也不等于固定一整段不可变化的节目旁白。

**双重审稿门槛：**
1. **事实 Gate**：准确、可追溯、时代与地理范围清楚、争议如实表达；
2. **游客 Gate**：无专业背景可理解、背景充分、故事/价值明确、不过度冗长、适合车内听、没有硬塞术语/年表。任一不合格不得发布为正式可讲知识。

## 4. 资料来源：L0—L6 按采集用途分层

**L 是“领域/用途分类”，不是可信度的绝对排序。** 必须按具体论断找到最直接的源，不要总让地方志或政府门户排第一。

| 层级 | 资料用途 | 重点来源/入口（发现目录，逐条复核） |
| --- | --- | --- |
| **L0 地名与基础地理** | 行政区、地名、位置、地理范围与空间关联 | 自然资源及行政区划/地名主管部门；国家基础地理信息中心 `https://www.ngcc.cn/`；天地图 `https://www.tianditu.gov.cn/` |
| **L1 自然地理、生态与科学** | 地质地貌、山川水系、气候、生态、形成机制 | 国家地球系统科学数据中心 `https://www.geodata.cn/`；中国地质调查局地质云 `https://geocloud.cgs.gov.cn/`；中国科学院、气象与生态科研机构 |
| **L2 交通、水利和重大工程** | 桥隧公铁、古今交通网络、工程建设与运行原理 | 交通运输部 `https://www.mot.gov.cn/`；水利部 `https://www.mwr.gov.cn/`；交通/水利地方部门、工程建设运营机构、设计资料、技术论文 |
| **L3 生活、物产、产业** | 农业、饮食、手艺、贸易、地方产业、普通人生活 | 农业农村部 `https://www.moa.gov.cn/`；地方农业/统计/文旅机构、实地调查与专题研究；地方志为补充 |
| **L4 人文与历史** | 文物、古籍、博物馆、非遗、民族文化、人物与地方史 | 四川省情网 `https://www.scsqw.org.cn/`；成都市情网及方志馆、县志/镇志；国家文物局有关原始公告；中国非遗网 `https://www.ihchina.cn/project/representative.html`；博物馆、古籍及地方档案 |
| **L5 专业研究和交叉核验** | 深度解释、纠错、历史/科学分歧、跨学科复核 | 国家哲学社会科学文献中心 `https://www.ncpssd.cn/`；学术期刊、专业专著、大学和科研机构、专业报告 |
| **L6 选题发现与叙事参考** | 发现旅行者感兴趣的问题、趣味线索、好故事切口 | 《中国国家地理》`https://www.dili360.com/`、《航拍中国》及其他专业纪录片、科普/旅行报道、可核实的旅行者观察。**不能把优质媒体/AI 摘要当作唯一事实证据，也不能复制其文稿/影像。** |

每个地区建立自己的 `Source Registry`（真实链接、作品/机构、出版版本及定位、核验状态、访问或出版时间、是否允许采集/再分发）。**有阅读权限不等于有抓取、离线镜像或二次发布权限。** 特别是地图、影像、地方志原文和技术图纸，需分别评估许可与中国境内测绘/坐标处理要求。

## 5. 证据分级 A—D（与 L 正交）

| 等级 | 含义 | 使用条件 |
| --- | --- | --- |
| **A 直接证据** | 官方原始公布文件、直接测量/调查、工程原始技术材料、版本明确的史料等 | 针对该论断直接有效且已核验，可优先依赖；原始文献“如此记载”不必然证明记载完全真实 |
| **B 专业研究** | 可定位的同行研究、学术论文、可靠专题报告/专著 | 对原因机制、历史分歧或跨资料解释提供支持；作者、版本和适用范围可核查 |
| **C 综合转述** | 专业媒体、可信科普、地方综合介绍 | 可用于发现和理解，但要辨明原出处、转引链和具体说法 |
| **D 待查线索** | 游记、社区、视频评论、AI 输出、搜索摘要、无出处说法 | 仅用于选题发现；不能单独写入正式可讲事实 |

**可信度须按“来源是否支持这句话”判定，不按域名一刀切**。同一内容的不同转载不算独立证据；重大冲突与高风险论断需独立来源复核。存档时保留支持、反证及来源之间的依赖关系。`verified` 的证据才可作肯定表达；`contested` 只有明确标注争议且审校过的谨慎表述可讲；`lead/rejected` 不进正式讲述。

## 6. 跨 AI/工具知识生产契约（内容契约定稿，机器字段可适配）

任何模型、Agent 或工作流必须能产出如下**概念实体**并让程序校验：

- **Area**：行政/地理身份与层级、名称/别名、有效年代、关联对象；空间 `geometry` 单独保留数据来源、许可、精度、版本，不能造多边形或用行政中心圆代表真边界。
- **Entity / Topic**：稳定ID、规范名和别名、类别多标签、适用区域/时代、关联 ID；避免杨慎/杨升庵这类别名被当成两个不同人物。
- **Claim（原子事实）**：稳定ID、主体、单一可核验陈述、时间/适用范围、稳定性`archival|stable|refreshable|realtime`、来源引用及原文准确定位、`verified|contested|lead|rejected` 等状态、核验时间、修订关系和保留的分歧。
- **Source**：稳定ID、作者/机构、标题、URL/DOI/ISBN 或馆藏标识、卷/章节/页码或网页小节、出版/检索时间、使用权/再分发状态、必要的内容版本信息。
- **Narrative editorial metadata**：游客背景引入、趣味点、白话解释、补充方向、与现场关联的前提及“不可声称眼前可见”的边界；与事实证据底稿分开，不直接把论文原文送给 TTS。
- **Pack manifest**：包ID、覆盖范围、内容/schema版本、更新时间、来源和许可声明、依赖项、大小/哈希及发布校验记录。

**生产中间表示推荐 UTF-8 JSON/JSONL + 可版本化 Schema + 程序验收报告；最终手机数据库、SQLite/JSON、字段命名及 Adapter 以真实工程验收为准。** 不允许把AI检索回复链接当`source_id`、随意补假页码、把未读的 URL 写“已核实”。Agent 必须说明实际检索到的证据与尚未能读取的资料，不编造过程成功。

## 7. 标准生产与核验流水线

`确定范围 → 寻找来源 → 实际查阅与书目定位 → 提取原子事实及支持证据 → 同名对象归一/去重 → 独立复核与争议处理 → 普通游客编辑 → 两重质量审查 → 版权/许可核对 → 结构与引用校验 → 正式发布与版本管理`

1. **发现**：先产候选对象、来源链接/书目信息和待查问题，不宣称事实已经核验。
2. **抽取**：分解一条条事实，准确记录支持它的原文位置、年代及地域；遇不到原文就标明未查到。
3. **复核**：独立回到可定位的原始出处；重大问题交叉核验。换一种模型**不等于**换了独立来源。
4. **内容编辑**：把专业研究底稿变成面向路过游客的分层讲述素材：给背景、说明趣味点、解释术语；历史/地理/工程/生活平等选题，不能为凑够某学科配额堆叠。
5. **发布**：程序检查唯一 ID、完整引用、来源有效性、状态门禁、许可、时间有效性、重复、包哈希；人对高风险说法和样本讲述听感终审。保留审计/纠错与下一次增量版本的路径。

**发布 P0 禁止：** 伪造出处或数据；AI 记忆当史料；未经许可镜像全文/地图/媒体；历史传说讲成定论；史料来源与结论错配；旧时效信息冒充实时；“位于本区”冒充“就在眼前”；专业数据堆砌到普通游客听不懂；为了好听新增没有证据的因果关系。

## 8. 知识包分层与长期交付方向

已确定的内容组织及分发方向：

- **全国基础包**：全国基础地名、行政身份索引及其他经合法获得、精度可靠的基础空间资料（需要独立验证可否覆盖全国/离线再分发）。
- **省级通识包**：跨市州的自然、人文、交通工程、文化与社会背景。
- **市州/城市详细包**：区县/镇乡街道、具体对象、可追溯 Facts、Overview/Topic 及关联。**有全国基础包即可独立安装城市包，不应被迫先下载完整省包。** 避免省市重复存相同事实。
- 下载管理体验借鉴高德离线包：按需下载、版本/大小/状态、校验、可更新/删除、失败保留旧包。**这些是后续产品架构，不代表 V0.4.0 已实现。**
- **GitHub Releases** 作为计划的正式二进制发布渠道；可独立建 `KITT-PACKS`，知识二进制与 App 主仓库分离，手机预下载并在旅途本地运行；**实际仓库、包格式和下载服务尚未建立，不能承诺已可下载**。
- **地图可选且独立**：未来评估 MapLibre 之类的开源渲染引擎，地图瓦片/PMTiles 等数据包与知识包分开发行；地图数据许可、坐标、精度和中国相关法规必须独立核查。KITT 不以做导航为目标。
- **长期稳定知识离线，实时问题联网**；无网络时直说无法确定实时状况。内容包与地图包、与应用版号、与线上研究证据缓存、与已播记忆各自独立。

## 9. 冻结范围、旧稿纠正与交付门槛

### 明确废止的旧草案/误读

- ❌ “KITT 是历史助手 / 用户是历史或地理专业人士 / 历史讲述永远优先。”
- ❌ “地方志始终为所有领域的唯一主干”或“资料权威等级等同 L0—L6 内容来源级别”。
- ❌ “默认必须80%历史/规定播报配额/固定历史→地理→特产顺序”。
- ❌ “每个区域都要凑够相同篇数、每条资料都写成百科文章或固定完整播报稿”。
- ❌ “上游研究数据越专业越应该原样讲给游客听”。
- ❌ “AI/纪录片/游记摘要可充当独立证据”。
- ❌ “V0.4.0 当前就需上线全国基础包、省包下载、GitHub 分发、NAS 自动生产或地图 SDK”。
- ✅ 现行版本采用**旅行助手优先、地点与趣味驱动、证据可追溯、零背景循序解释、深度可按需追问**的标准。

### 哪些已经定稿，哪些仍待验证

- **已经定稿**：定位、六类知识范围、L0—L6 来源用途、A—D 证据等级理念、证据/版权门禁、普通游客编辑原则、结构化原子事实、地理范围不猜、长期三级分包与 GitHub Releases 的方向、地图和知识包分离。
- **尚未声称实现/冻结**：V0.4.0 实际 Schema 与本规范之间的 Adapter、可合法分发的全国区划边界数据、具体知识包文件格式/大小、GitHub Releases 仓库及自动下载器、滑块档位/默认值、地图 SDK 与离线瓦片、NAS 批量流水线。需要单独授权并实测后作工程冻结。
