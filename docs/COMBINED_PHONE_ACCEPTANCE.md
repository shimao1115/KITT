# V0.2 联合手机验收

本批次没有连接或操作手机。以下各项均为 **DEFERRED TO COMBINED PHONE ACCEPTANCE**，
自动测试与历史 M1.1–M1.4 手机证据不替代本次结果。中文 ASR 不在此清单中，不需要修复 OEM 识别器。

准备：安装 `artifacts/kitt-v0-debug.apk`（`adb install -r` 或手机打开 APK），升级保留设置。
新装默认 Fake，可先验生命周期。真实内容／图片测试使用设置中的 ChatGPT 账号及账号实际列出的支持图片模型；
若会话过期，用户本人在系统浏览器重新授权。普通 API 为可选替代，无需为 Fake 验收输入密钥。

1. **声音／状态**：设置选一个本地 TTS 声音 → 试听、保存、系统返回、重启；确认保留。
   自动讲述显示慢速红色 scanner，安静无 scanner；点击“说点什么”立即停止 TTS、转入监听状态。
   如系统识别启动失败，应显示准确简短提示；不把这项记为中文 ASR 成功，也不要求修复 ASR。
2. **真实 GPS／位置**：普通“开始读山河”显示手机 GPS；有新鲜物理定位后，出现简洁区县＋镇街标签。
   Android Geocoder 缺失／不可用时允许坐标或未知降级，旅程继续。不要把室内仅注册 listener 算作户外定位 PASS。
3. **真实 ChatGPT 题材**：设置测试 Director 连接，再进入旅程；观察自然地理、文化历史、产业／习俗等可解释角度。
   SILENT 合法，无固定篇数或机械轮换；“再讲一点”仍深入当前主题（可使用开发入口的文本输入，无需 ASR）。
4. **广汉／三星堆及独立地标**：标题点五次 → 100 km/h / 16× / 开始；Context／开发日志中可发现三星堆。
   即使章节未变，接近当前参考节点也可有 `landmark opportunity`；优先有依据的重要事件，不强迫讲话。
   三星堆、年画村、龙门山山前和雎水太平桥仅为粗粒度区域参考，不能说眼前可见、正在过桥或报未核实数字。
5. **路线截图**：结束／返回出发页 → 添加路线参考图 → 等待一句简短提示 → 开始。
   后续 Context 有文字 RouteHint，GPS 优先；不每次发送原图。取消／清除／结束后不残留。Fake 明确提示不支持图片。
6. **旅途看图**：乘客或停车时，从相册选图、系统相机拍照分别测试；默认“帮我看看这个”，再试一个短文本问题。
   当前所选模型收到图并正常解释／TTS；以后自动检查不带旧图。取消相机、无图片、不支持模型或网络失败有简短说明。
   旋转／重启／结束后不留待播照片；照片方向、URI 授权、实体模型图片能力需真机确认。
7. **真实／模拟隔离**：开发模拟显示“新都→安州雎水”；结束 → 返回 → 普通开始恢复手机 GPS，不留路线标签。
8. **100 km/h / 16× 全程**：起点成都市新都区，终点绵阳市安州区雎水镇，29点／13章节。
   思考、TTS、监听或看图时暂停模拟移动；其余加速。观察缓存刷新、题材与独立地标机会，过时内容不补播。
   安静仍计真实10分钟；可提前结束安静。跳过／主动文本接管优先；不要把 Fake 固定句子当真实内容 PASS。
9. **后台／锁屏**：在旅程中锁屏或切后台持续至少10分钟；有位置时自动判断／本地 TTS继续，通知可结束。
   后台不发需要即时回答的新问题；返回后没有过时补播。记录 OEM 电池策略和异常，而非悄悄改权限。
10. **结束／纪要／清理**：主动结束（含思考／讲话／看图时）→ 简短纪要 → 返回；通知／位置监听停止。
    无持续录音、恢复的旧图片或 RouteHint；下次开始清空章节／节点去重，重新从当前现场判断。
11. **最终横竖屏**：白天浅色、夜间黑红；读山河／讲述／监听／安静清楚可区分。
    小屏竖屏及横屏主按钮／当前地点可见，驾驶页不需滚动；看图入口次要。设置、选图、相机返回和旋转可用。

最短合并顺序：声音保存 → 普通 GPS → 结束 → 路线截图 → 开发100/16全程（含题材、地标、追问、安静、看图）
→ 锁屏 → 结束纪要 → 普通 GPS → 横竖屏。记录每项 PASS／未通过及原因，不重开中文 ASR 里程碑。

V0.2 只有四个带来源的空间参考，未承诺全国 POI 自动发现；几何支持所有地标类型，缺少有依据的地点时允许安静。
当前 Adapter 没有开启联网搜索。账号级搜索能力探测可留作后续增强；当前稳定事实／删去不可核实细节的降级已可运行。
