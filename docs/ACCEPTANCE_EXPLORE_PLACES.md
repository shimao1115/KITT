# V0.5.1/code18 探索地点工程验收

本轮任务是 [Issue #30](https://github.com/shimao1115/KITT/issues/30)，交付到 [Draft PR #31](https://github.com/shimao1115/KITT/pull/31)。只做本地工程，不操作手机、不合并、不上传或发布 APK。

## 内容与入口

首页保留「开始沿途」，停驶态新增「探索地点」。不需要开始旅程、GPS、麦克风、网络或云账号。正在旅程中隐藏探索入口，不因切页修改旅程。列表来自校验成功的实际资料，当前只有四川省成都市新都区，6 对象、22 条基础事实、6 个来源；没有虚构其它县、镇街或对象现场坐标。

县级列表 → 关键词搜索对象名/事实正文/可用故事全文 → 对象详情。事实保留独立条目及对应来源名、可复制网址和检索日期，明确本次未联网；不拼装成完整故事，不强行把旧 TopicFamily 转为六类。无包或校验失败、搜索无结果、无合格故事均有明确提示。来源网址仅展示，不主动获取网页。

标准 Debug、Release 及本版 runtimecheck 的探索页均使用严格故事加载。真实杨慎两篇仍 candidate/visitor_gate=pending，正式可读可播完整故事 **0**。探索不会提升 Gate；现有独立 story-preview 仪器入口的候选判定机制保留，本版 runtimecheck 未注入两篇候选资产。

## 合格故事与语音的测试范围

测试在内存中使用显式 `TEST_ONLY` 审批夹具，通过既有 StoryPacks 的事实、来源、修订、哈希、版权、审核校验后才交给页面。主篇和延伸各为独立文章；正文逐字相同，页面不截取、不改写、不自动连播。测试审批不会写回真实文件或 APK。

播放仅在文章页点击。专用 AndroidVoice 复用已有中文声音选择、分段与超时机制，使用当前保存的音色/语速并强制离线；没有已安装离线中文声音就拒绝朗读并提示。浏览器自己的控制器不持有 Journey、TripStore、GPS 或云 Provider，不记沿途已播。停止、返回、文本切换、离页、后台、旋转或恢复均不续播；成功/失败/异常/超时后允许再次手动播放，旧回调被丢弃。没有不可靠的暂停按钮。

最终计数、逐套测试结果、日志哈希、六组模拟、lint 和候选 APK 大小/哈希见 [本轮工程证据](evidence/v051-verification.json)；运行日志在本地 artifacts。Compose/Robolectric 覆盖手机 411×914dp 竖屏、914×411dp 横屏、1280×800dp 平板横屏、320×568dp/1.5 倍字体的可滚动正文和可见返回/播放控件。状态恢复测试保留文章和搜索，但不恢复播放；后台测试停止语音。测试还比较合成的20份旧纪要与设置文件前后哈希，并检查未启动 Journey、未改定位/已播记录/云计数。

以上均为 JVM/Android shadow/合成内容证据，不代表 vivo X200 Pro、Samsung Tab S9 的真实屏幕、键盘、系统侧滑返回或中文 TTS 耳听已验。没有生成或冒用设备截图。旧 #23/#24/#27 外场项目继续 OPEN/PENDING。

V0.5.0/code17 双篇已有的真人完整耳听 PASS 继续有效；本轮没有重装或重听，也不改写旧仪器记录。此处设备 PENDING 指 code18 的新探索入口与实际设备行为。
